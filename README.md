# qda

**HR CLIMB — Interactive Career Journey** — a self-contained, single-page web
app that guides junior HR professionals through an interactive career-development
journey (Career Awareness, Ladder Mapping, Individual Assessment, Mentoring &
Mobility, Building the Future, plus appendices and a personal dashboard).

The entire application ships as one static file, `index.html`, with all styles
and behaviour inlined and no build step or external JavaScript dependencies.

Maintained by Quantum Link Digital Agency.
